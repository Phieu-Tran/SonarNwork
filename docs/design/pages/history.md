# History page

History is a dedicated primary view, not a panel appended to every workflow.
It supports finding, reopening, deleting, and comparing saved diagnostic runs.

- Loading, no saved runs, and no search matches are distinct states.
- Comparison requires two selections; show a short selection hint before the
  comparison panel is available.
- Reopening a run returns the user to its workflow and closes History.
- Keep timestamps, workflow/check identity, target, and verdict scannable before
  secondary facts.
