# Suggested Commands
- Rust CLI: `cargo run -p sonar-cli -- <command>` from repo root.
- Rust tests: `cargo test --workspace` from repo root.
- Rust checks: `cargo check --workspace`, `cargo clippy --workspace`, `cargo fmt --all`.
- Frontend unit tests: `pnpm test` from `app/` (Vitest).
- Frontend build: `pnpm build` from `app/`.
- Desktop dev: `pnpm tauri dev` from `app/`.
- Windows discovery: prefer `rg --files` and `rg -n`; PowerShell is the shell.
